# 🎮 Game Save Scanner

Утилита для автоматического поиска и каталогизации игровых сохранений на вашем ПК. Сканер проверяет типовые папки (Steam, AppData, Saved Games и др.), определяет названия игр (в том числе по Steam AppID) и генерирует удобный HTML-отчет.

## ✨ Возможности

*   **🔍 Глубокое сканирование**: Проверяет все подключенные диски и стандартные пути сохранения игр logic.
*   **📦 Поддержка Steam**:
    *   Автоматически находит библиотеки Steam.
    *   Преобразует непонятные `AppID` (например, `3017860`) в реальные названия игр (читая локальные манифесты).
    *   Имеет встроенную базу данных для "остаточных" сохранений удаленных игр.
*   **🛡️ Система Бэкапов**: Встроенная функция резервного копирования всех найденных сохранений в `V:\backup-saved-games` с сохранением полной структуры путей.
*   **🌐 Веб-интерфейс**: Удобный локальный сайт для просмотра отчета и управления бэкапами.
*   **📊 HTML Отчет**: Генерирует красивый `index.html` с таблицами, сортировкой и группировкой.

## 🚀 Как пользоваться

### Требования
*   Установленный **Python 3.x**.
*   Стандартные библиотеки (ничего дополнительно устанавливать через pip не нужно).

### Запуск
1.  Откройте терминал в папке с проектом:
    ```bash
    cd ./os
    ```

2.  Запустите сервер:
    ```bash
    python main.py
    ```
    *Скрипт автоматически запустит сканирование и откроет веб-отчет в вашем браузере (обычно http://localhost:8000).*

3.  **Создание Бэкапа**:
    *   Нажмите кнопку **📦 Backup All Saves** в верхнем углу отчета.
    *   Сохранения будут скопированы в `V:\backup-saved-games\[Дата_Время]\[НазваниеИгры]\[ОригинальныйПуть]`.
    *   Пример пути: `V:\backup-saved-games\2026-01-25_12-00-00\DOOM The Dark Ages\OfflineSTEAM\userdata\1482238173\3017860`.

## 📂 Структура проекта

*   `main.py` — Запускает локальный веб-сервер и сканирование.
*   `save_searcher.py` — Логика поиска. Содержит алгоритмы сканирования дисков, разбора папок Steam и базу AppID.
*   `html_reporter.py` — Генератор HTML-отчета. Содержит JS/CSS для веб-интерфейса.
*   `backup_manager.py` — Модуль резервного копирования.

## ❓ FAQ

**В: Скрипт не нашел мою игру!**
О: Сканер ищет в самых популярных местах (`Saved Games`, `Documents`, `AppData`, `Steam/userdata`). Если игра хранит сохранения в нестандартной папке (например, прямо в папке установки игры без привязки к Steam), она может быть пропущена.

**В: В отчете есть "Steam App 12345", что это?**
О: Это игра, для которой сканер не смог найти название. Она не установлена в текущих библиотеках Steam, и её ID нет в нашей встроенной базе. Вы можете погуглить этот ID, чтобы узнать название игры.

**В: Как добавить название для неизвестного App ID?**
О: Вы можете добавить ID и название игры вручную в словарь `STEAM_APPID_FALLBACK` в файле `save_searcher.py`.
