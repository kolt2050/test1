# System See

**System See** is a local web application for monitoring file system changes on the C: drive. It allows you to take snapshots of the file system and compare them to detect added, modified, or deleted files.

## 🚀 Quick Start

1.  **Install Python** (if not installed).
2.  **Install Flask**:
    ```bash
    pip install flask
    ```
3.  **Run the application**:
    ```bash
    python app.py
    ```
4.  **Open Browser**: Go to [http://127.0.0.1:5000](http://127.0.0.1:5000)

---

## 📂 File Structure

### ✅ Mandatory Files (DO NOT DELETE)
These files are essential for the application to function. If you are copying this project to a new folder, you **must** include these:

*   **`app.py`**: The main application server (Flask). Handles web routes and server logic.
*   **`database.py`**: Manages the SQLite database operations (saving scans, fetching history).
*   **`scanner.py`**: Contains the logic for scanning the C: drive and filtering files.
*   **`monitor.py`**: Handles the comparison logic between different scan snapshots.
*   **`templates/index.html`**: The frontend user interface (HTML/JS/CSS).
*   **`ignore_patterns.txt`**: Configuration file for defining which files/folders to ignore.

### 🗑️ Disposable / Generated Files (SAFE TO DELETE)
These files are generated by the application during runtime. You can delete them to reset the project state or when moving to a new environment:

*   **`system_see.db`**: The SQLite database containing scan history.
    *   *Effect of deletion*: All scan history is lost. A new empty DB will be created on next launch.
*   **`__pycache__/`**: Folder containing compiled Python files.
    *   *Effect of deletion*: Regenerated automatically. Safe to delete.
*   **`*.log`** (if any): Log files created during execution.
    *   *Effect of deletion*: History of logs lost. Safe to delete.
*   **`*.tmp`**: Temporary files.

---

## ⚙️ Configuration

### Ignoring Files
Edit **`ignore_patterns.txt`** to exclude specific files or folders from the scan.
*   Supports wildcards (e.g., `*.tmp`, `*cache*`).
*   Patterns apply to the **full path**.
*   **Example**:
    ```text
    *.log
    *temp*
    *cache*
    *google*
    ```

## 📂 Структура файлов

### ✅ Обязательные файлы (НЕ УДАЛЯТЬ)
Эти файлы необходимы для работы приложения. Если вы копируете проект в новую папку, вы **обязаны** перенести их:

*   **`app.py`**: Главный сервер приложения (Flask). Отвечает за маршруты и логику.
*   **`database.py`**: Управляет базой данных SQLite (сохранение сканирований, история).
*   **`scanner.py`**: Содержит логику сканирования диска C: и фильтрации файлов.
*   **`monitor.py`**: Отвечает за сравнение снимков (поиск различий).
*   **`templates/index.html`**: Интерфейс пользователя (HTML/JS/CSS).
*   **`ignore_patterns.txt`**: Файл настроек для игнорирования файлов/папок.

### 🗑️ Временные / Генерируемые файлы (МОЖНО УДАЛЯТЬ)
Эти файлы создаются программой во время работы. Их можно смело удалять для сброса состояния или при переносе проекта:

*   **`system_see.db`**: База данных SQLite с историей сканирований.
    *   *Что будет, если удалить*: Вся история сканирований пропадет. При следующем запуске создастся новая пустая база.
*   **`__pycache__/`**: Папка с скомпилированными файлами Python.
    *   *Что будет, если удалить*: Создастся заново автоматически. Можно удалять.
*   **`*.log`** (если есть): Лог-файлы.
    *   *Что будет, если удалить*: Пропадет история логов. Можно удалять.
*   **`*.tmp`**: Временные файлы.

*   Шаблоны применяются к **полному пути**.
*   **Пример**:
    ```text
    *.log
    *temp*
    *cache*
    *google*
    ```
