# Документация: Записная книжка (Notebook)

Это настольное приложение для ведения заметок с поддержкой форматирования текста (Rich Text), иерархической структурой и возможностью экспорта в HTML. Приложение упаковано с использованием Electron для работы в Windows.

---

## 🎮 Элементы управления

### 1. Боковая панель (Sidebar)
*   **Заголовок "Заметки"**: Сверху расположены кнопка переключения темы (Луна/Солнце) и кнопка создания корневой заметки (`+`).
*   **Список заметок**: 
    *   **Шеврон (▶)**: Разворачивает/сворачивает подзаметки.
    *   **Заголовок**: Клик выбирает заметку для редактирования.
    *   **Кнопка `+` (при наведении)**: Создает вложенную подзаметку для данной заметки.
    *   **Сортировка**: Весь список автоматически сортируется по алфавиту (А-Я).
*   **Футер (Нижняя часть)**:
    *   **Импорт HTML**: Позволяет загрузить заметки из ранее экспортированного HTML-файла (заменяет текущую сессию).
    *   **Экспорт всех (HTML)**: Сохраняет все заметки в один файл с сохранением иерархию.

### 2. Панель инструментов редактора (Toolbar)
*   **B, I, U**: Жирный, курсив, подчеркивание.
*   **Выравнивание**: По левому краю, по центру, по правому краю.
*   **Скачать (Иконка)**: Экспортирует только текущую открытую заметку в HTML.
*   **Удалить (Корзина)**: Удаляет текущую заметку. Если у нее есть подзаметки, они будут удалены вместе с ней (после подтверждения).

### 3. Область редактирования
*   **Заголовок**: Поле для ввода названия, центрировано для удобства.
*   **Лист "Бумаги"**: Область для ввода текста. 
    *   **Авто-ссылки**: При вводе URL и нажатии Пробела или Enter текст автоматически превращается в ссылку.
    *   **Баббл ссылки**: При клике на ссылку появляется меню для копирования, редактирования или удаления ссылки.
    *   **Прокрутка**: Если текст длинный, область прокручивается независимо, оставляя панель инструментов зафиксированной сверху.

---

## 🛠 Технические особенности

*   **Темы**: Приложение поддерживает два режима. Выбор сохраняется в `localStorage` и восстанавливается при перезапуске.
*   **Хранение данных**: Все заметки хранятся в `localStorage` браузера (или Electron).
*   **Безопасность**: Для удаления веток заметок или импорта файлов используются кастомные модальные окна подтверждения.
*   **Сборка**: Скрипт `npm run dist` создает готовый установщик для Windows в папке `dist`.
